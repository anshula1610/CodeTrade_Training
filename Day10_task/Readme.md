# 📊 CodeTrade Day 10 Tasks – Pandas & SQL Practice

## 📌 Project Overview

This notebook contains the Day 10 practical tasks from the CodeTrade AI/ML Internship. The exercises focus on **data manipulation using Pandas** and **database operations using SQLite (SQL)**. The notebook demonstrates fundamental data analysis techniques, including data cleaning, aggregation, merging, reshaping, and SQL integration.

---

## 🎯 Objectives

- Learn data manipulation with Pandas.
- Perform data cleaning and preprocessing.
- Practice grouping and aggregation.
- Merge multiple datasets.
- Reshape data using pivot tables.
- Handle missing values effectively.
- Store and query data using SQLite.
- Compare SQL operations with Pandas.
