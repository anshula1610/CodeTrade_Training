# LLM Fundamentals & APIs Project

## Overview

This project demonstrates the practical use of Large Language Models (LLMs) and Generative AI APIs using Google's Gemini API. The project covers model comparison, prompt engineering, conversational AI development, and token usage analysis.

## Objectives

* Understand the fundamentals of Large Language Models (LLMs).
* Learn how to integrate and use Generative AI APIs.
* Compare responses from different Gemini models.
* Explore prompt engineering techniques.
* Build an interactive AI chatbot.
* Analyze token usage and estimate API costs.

## Task 1: Multi-LLM Response Comparison Tool

### Description

This task compares the responses generated by different Gemini models for the same prompt.

### Features

* Response generation using multiple Gemini models.
* Comparison of response quality and length.
* Export results to CSV format.

### Output

* `llm_comparison_results.csv`

---

## Task 2: Prompt Engineering Playground

### Description

This task explores different prompting techniques to evaluate how prompt design influences AI responses.

### Prompting Techniques

* Zero-Shot Prompting
* Few-Shot Prompting
* Chain-of-Thought Prompting

### Features

* Generates responses for multiple prompt styles.
* Compares output quality and structure.
* Saves results for further analysis.

### Output

* `prompt_engineering_results.csv`

---

## Task 3: Streaming AI Chat Assistant

### Description

An interactive command-line chatbot powered by Gemini API.

### Features

* Real-time user interaction.
* Multiple-turn conversation support.
* Exit functionality using "exit" or "quit".

### Example

```
You: What is Artificial Intelligence?

AI: Artificial Intelligence (AI) is a branch of computer science that enables machines to perform tasks that typically require human intelligence.
```

## Task 4: Token Usage & Cost Tracker

### Description

Tracks token consumption and estimates API usage costs.

### Features

* Calculates approximate token usage.
* Estimates API cost based on token count.
* Stores results in CSV format.

### Output

* `token_usage_report.csv`
